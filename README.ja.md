# MyDock

ウィジェット、区切り、アプリのグループを備えた macOS 用の Dock です。Apple の Dock と並べて、または Apple の Dock の代わりに使え、システムには手を加えません。

## ダウンロードとインストール

1. [最新リリース](https://github.com/JotaRguezD/MyDock/releases/latest)から **`MyDock-x.y.z.dmg`** をダウンロードします。
2. `.dmg` を開き、**MyDock** を **アプリケーション** フォルダにドラッグします。
3. アプリケーションから MyDock を開きます。

### 初めて開くとき

MyDock は Apple が確認したデベロッパによる署名ではないため、初回は macOS がそのままでは開きません：

- **macOS 15 Sequoia 以降**：警告が表示されたら **完了** をクリックします。**システム設定 › プライバシーとセキュリティ** を開き、一番下までスクロールして MyDock の横の **このまま開く** をクリックし、パスワードで確認します。
- **macOS 14 Sonoma**：アプリケーションで MyDock を右クリックし、**開く** を選んで確認します。

この操作は一度だけです。アップデートも同じ方法でインストールします。新しい `.dmg` をダウンロードし、MyDock をアプリケーションにドラッグして古いものと置き換えてください。設定と許可はそのまま引き継がれます。

### 動作環境

- macOS 14 Sonoma 以降。
- Intel プロセッサまたは Apple シリコン（M1、M2、M3…）を搭載したすべての Mac。

## できること

### アプリ、フォルダ、グループ

- **アプリやフォルダを固定**：Finder からドラッグするだけです。並べ替えるには、Dock 内でアイコンをドラッグします。
- **起動中のアプリ**：固定していないアプリは、Apple の Dock と同じように固定したアプリの後ろに自動で表示されます。アイコンの下の点は、そのアプリが起動中であることを示します。
- **グループ**：複数のアプリを 1 つのアイコンにまとめます。クリックするとすべてのアプリを含む小さなウインドウが開きます。アプリをグループにドロップすると追加できます。
- **区切りとスペース**：好きな場所に、好きなだけ追加できます。
- **ゴミ箱**：Apple の Dock と同じく右端にあります。クリックで開き、ファイルをドロップするとゴミ箱に移動、Dock のアイコンをドロップすると Dock から削除できます。右クリック › **ゴミ箱を空にする…**（必ず確認があります）。設定で非表示にできます。
- **アプリとウィジェットは別のエリアに**：先にアプリ、その後にウィジェットが並び、間に区切りが入ります。
- **アニメーション**：アプリを開くと、起動が終わるまでアイコンが弾みます。ウィジェットはクリックすると小さく反応します。

### アプリを右クリック

| アプリ | オプション |
|---|---|
| 固定済み | Finderに表示 · グループに移動 · Dockから削除 · **終了** |
| グループ内 | Dockに出す · グループから削除 · **終了** |
| 起動中で未固定 | Dockに残す · **終了** |

**終了** は常に最後の項目で、アプリが起動していないときはグレイで表示されます。

### 16 種類のウィジェット

| 基本 | 仕事 | システム | ユーティリティ |
|---|---|---|---|
| 時計と日付 | 今後の予定 | バッテリー | ダウンロード |
| 天気 | リマインダー | 音量 | スクリーンショット |
| ミュージック | ポモドーロ | クリップボード | 検索 |
| CPUとメモリ | クイックメモ | ディスクとネットワーク | カラーピッカー |

- **時計と日付**：クリックするとカレンダーが開きます。
- **天気**：現在地または保存した都市の天気です。右クリック › **都市** ですばやく切り替えられます。クリックすると天気アプリが開きます。
- **ミュージック**：Spotify またはミュージックで再生中の曲と、前へ・再生/一時停止・次へのボタン。クリックするとプレーヤーが開きます。
- **CPUとメモリ**、**ディスクとネットワーク**：リアルタイムの使用状況。クリックするとアクティビティモニタが開きます。
- **今後の予定**：カレンダーの次の予定と、開始までの時間。
- **リマインダー**：未完了のタスク。Dock から直接完了にできます。
- **ポモドーロ**：集中と休憩のタイマー。終了時にサウンドでお知らせします。
- **クイックメモ**：書いた短いテキストが Dock に保存されます。
- **バッテリー**：残量と充電中かどうか。
- **音量**：消音ボタンと音量スライダ。
- **クリップボード**：最近コピーした内容を、クリック 1 回でもう一度コピーできます。
- **ダウンロード** と **スクリーンショット**：最新のファイルを開いたり、ほかのアプリにドラッグしたりできます。
- **検索**：Spotlight を開かずにアプリやファイルを探せます。
- **カラーピッカー**：画面上の好きな場所の色を取得し、そのコードをコピーします。

各ウィジェットは 1 つずつしか追加できません。

### カスタマイズ

- **各ウィジェット**：**コンパクト表示**（アイコンサイズ）または **ワイド表示**、**背景色**、それぞれのオプション：12 時間/24 時間表示、秒、天気の都市、°C/°F、ポモドーロの分数、表示する項目数…
- **位置**：下、左、右。
- **アイコンのサイズ**：小、中、大。
- **自動的に隠す**：Dock が隠れ、ポインタを画面の端に移動すると再び表示されます。
- **使用するDock**：MyDock のみ、MyDock と Apple の Dock、または Apple の Dock に戻す。
- **ウインドウをDockに合わせる**（オプション）：最大化したウインドウが、Apple の Dock と同じように MyDock の手前で止まります。Dock を自動的に隠す設定のときは、ウインドウが画面全体に広がります。アプリがフルスクリーンのときは MyDock が隠れ、ポインタを端に移動すると表示されます。
- **ログイン時に開く**。
- **ライトモード/ダークモード**：Mac の設定に従います。
- **17 言語**：英語、スペイン語、カタルーニャ語、ガリシア語、バスク語、フランス語、ドイツ語、イタリア語、ポルトガル語、ノルウェー語、デンマーク語、フィンランド語、日本語、簡体字中国語、韓国語、ヒンディー語、アラビア語。Mac の言語、または設定で選んだ言語を使います。

## 使い方

- **Dock の背景を右クリック**：区切り、スペース、グループ、ウィジェットの追加と、主なオプション（位置、サイズ、隠す、使用する Dock…）。
- **ウィジェットを右クリック**：設定、コンパクト/ワイド表示の切り替え、削除。
- **設定…**（背景の右クリックメニュー内）：すべてのオプションをまとめたウインドウ。左側に **一般** と各ウィジェットの項目があり、**+** ボタンでウィジェットを追加できます。

> Apple の Dock では、アイコンをほかのアプリにドラッグできません。外にドラッグするとアイコンが削除されます。アプリは Finder から MyDock に追加してください。

## 許可

MyDock は必要になったときだけ許可を求め、macOS がそれを記憶します：

| 用途 | 許可 |
|---|---|
| 現在地の天気 | 位置情報（任意：許可しない場合は都市を手動で追加） |
| ミュージックとゴミ箱 | Spotify またはミュージック、および Finder の操作（ゴミ箱に項目があるかの確認と空にするため） |
| 今後の予定 | カレンダー |
| リマインダー | リマインダー |
| ダウンロード | ダウンロードフォルダ |
| スクリーンショット | デスクトップフォルダ（またはスクリーンショットの保存先） |
| ウインドウをDockに合わせる | アクセシビリティ |

許可しない場合、ウィジェットには「許可なし」と表示されます。クリックすると許可するための設定が開きます。

## プライバシー

- アカウントも分析もありません。設定はあなたの Mac にだけ保存されます。
- 天気ウィジェットが [Open-Meteo](https://open-meteo.com) に送るのは、気温を取得するための丸めた座標（精度約 1 km）だけです。都市名は Apple のマップサービスで検索します。
- クリップボードの履歴はメモリ上にのみ保持されます。ディスクには書き込まれず、MyDock を終了すると消え、パスワードマネージャがコピーした内容は含まれません。

## セキュリティ

- **macOS の Hardened Runtime**：ほかのプログラムが MyDock にコードを注入して、その許可を悪用することはできません。また、MyDock が求められるのは上の表の許可だけです。
- **署名**：すべてのバージョンが同じ証明書で署名されているため、macOS はアップデートを同じアプリとして認識し、許可を引き継ぎます。
- **`.dmg` が本物か確認する**：各リリースのページで、GitHub は *Assets* の `.dmg` の名前の横に SHA-256 フィンガープリントを表示します。ターミナル App で次のように入力します：

  ```bash
  shasum -a 256 ~/Downloads/MyDock-x.y.z.dmg
  ```

  結果がそのフィンガープリントと完全に一致する必要があります。一致しない場合は開かないでください。
- MyDock は[公式のリリースページ](https://github.com/JotaRguezD/MyDock/releases)からのみダウンロードしてください。

## よくある質問

**Apple の Dock を表示しないようにできますか？**
はい。右クリック › **使用するDock › MyDockのみ**。MyDock を終了すると、Apple の Dock は元どおりに戻ります。MyDock が予期せず終了したり、強制終了したりした場合も同様です。

**ウインドウを最大化すると MyDock の下に潜り込みます。**
設定 › 一般 で **ウインドウをDockに合わせる** をオンにし、アクセシビリティの許可を与えてください。

**聴いている曲が表示されないのはなぜですか？**
ミュージックウィジェットは Spotify と Apple のミュージックに対応しています。ほかのプレーヤーは検出されません。

## アンインストール

1. **ログイン時に開く** をオフにして、**MyDockを終了** を選びます。「MyDockのみ」を使っていた場合、Apple の Dock は元どおりに戻ります。
2. アプリケーションから MyDock を削除します。
3. 設定も削除したい場合は、フォルダ `~/Library/Application Support/MyDock` を削除します。
