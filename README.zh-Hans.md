# MyDock

一款适用于 macOS 的程序坞，带有小组件、分隔线和 App 群组。可以与 Apple 程序坞同时使用，也可以取而代之，且不会修改系统。

## 下载和安装

1. 从[最新版本](https://github.com/JotaRguezD/MyDock/releases/latest)下载 **`MyDock-x.y.z.dmg`**。
2. 打开 `.dmg`，将 **MyDock** 拖到 **应用程序** 文件夹。
3. 从“应用程序”中打开 MyDock。

### 首次打开

MyDock 没有经过 Apple 验证的开发者签名，因此首次打开时 macOS 不会直接打开它：

- **macOS 15 Sequoia 或更高版本**：会看到一条警告，点按 **完成**。前往 **系统设置 › 隐私与安全性**，滚动到底部，点按 MyDock 旁边的 **仍要打开**，并输入密码确认。
- **macOS 14 Sonoma**：在“应用程序”中按住 Control 点按（或右键点按）MyDock，选择 **打开** 并确认。

只需操作一次。更新的安装方式相同：下载新的 `.dmg`，将 MyDock 拖到“应用程序”替换旧版本。你的设置和权限都会保留。

### 系统要求

- macOS 14 Sonoma 或更高版本。
- 任意 Mac：Intel 处理器或 Apple 芯片（M1、M2、M3…）。

## 功能

### App、文件夹和群组

- **固定 App 和文件夹**：从访达拖到程序坞即可；点按文件夹会在访达中打开它。在程序坞内拖动图标可调整顺序。
- **已打开的 App**：未固定的 App 会自动显示在已固定 App 之后，就像 Apple 程序坞一样。图标下方的圆点表示该 App 已打开。
- **群组**：将多个 App 放进一个图标；点按后会打开一个包含所有 App 的小窗口。把 App 拖到群组上即可加入。
- **分隔线和空格**：想加多少就加多少，想放哪里就放哪里。
- **废纸篓**：和 Apple 程序坞一样位于最末端。点按即可打开；把文件拖到上面可移到废纸篓，把程序坞图标拖上去可将其移除；右键点按 › **清倒废纸篓…**（始终会要求确认）。可在设置中隐藏。
- **App 和小组件分区显示**：先是 App，再是小组件，中间有分隔线。
- **动画**：打开 App 时，图标会跳动直到打开完成；点按小组件时会有轻微的脉冲效果。

### 右键菜单

菜单会在程序坞正上方打开，并带有一个指向图标的小箭头，与 Apple 程序坞一样，因此不会遮住旁边的图标：右键点按另一个图标，它的菜单会立即打开。App、小组件、群组、废纸篓和程序坞背景都是如此。

| App | 选项 |
|---|---|
| 已打开 | 它的窗口 · 来自其“文件”菜单的主要操作（新建窗口、新建日程…） · **选项** › · 隐藏 · **退出** · 强制退出 |
| 已固定，未打开 | 在访达中显示 · 移到群组 · 从程序坞中移除 · 退出（灰色） |
| 在群组中，未打开 | 移到程序坞 · 从群组中移除 · 退出（灰色） |

在 **选项** 中，已打开的 App 与未打开时的选项相同（如未固定，则为 **在程序坞中保留**）。窗口和操作需要“辅助功能”权限。每个程序坞显示自己的菜单：在 Apple 程序坞中右键点按，仍会打开 Apple 的菜单。

### 16 个小组件

| 基础 | 效率 | 系统 | 工具 |
|---|---|---|---|
| 时钟和日期 | 即将发生的日程 | 电池 | 下载 |
| 天气 | 提醒事项 | 音量 | 截屏 |
| 音乐 | 番茄钟 | 剪贴板 | 搜索 |
| CPU 和内存 | 快速备忘录 | 磁盘和网络 | 取色器 |

- **时钟和日期**：点按打开“日历”。
- **天气**：显示你所在位置或已存储城市的天气；右键点按 › **城市** 可快速切换。点按打开“天气” App。
- **音乐**：显示任意 App（Spotify、“音乐”、浏览器…）中正在播放的歌曲，带有上一首、播放/暂停和下一首按钮。点按打开正在播放的 App。
- **CPU 和内存**、**磁盘和网络**：实时用量；点按打开“活动监视器”。
- **即将发生的日程**：你的下一个日历日程以及距开始还有多久。
- **提醒事项**：你的待办事项，可直接在程序坞中标记为已完成。
- **番茄钟**：专注与休息计时器，结束时会有提示音。
- **快速备忘录**：写下的一段文字会保存在程序坞中。
- **电池**：电量百分比以及是否正在充电。
- **音量**：静音按钮和音量滑块。
- **剪贴板**：最近拷贝的内容，点按一下即可再次拷贝。
- **下载** 和 **截屏**：最近的文件，可打开或拖到其他 App 中。
- **搜索**：无需打开“聚焦”即可查找 App 和文件。
- **取色器**：从屏幕任意位置取色并拷贝其代码。

每个小组件只能添加一次。

### 自定义

- **每个小组件**：**紧凑版**（图标大小）或 **宽版**、**背景颜色**以及各自的选项：12 或 24 小时制、秒、天气城市、°C 或 °F、番茄钟分钟数、显示项目数量…
- **位置**：底部、顶部、左侧或右侧。放在顶部（菜单栏下方）时，可以只放小组件，与 Apple 程序坞并存。
- **图标大小**：小、中或大。
- **自动隐藏**：程序坞会隐藏，将指针移到屏幕边缘时再次出现。
- **使用的程序坞**：仅 MyDock、MyDock 和 Apple 程序坞，或恢复为 Apple 程序坞。
- **窗口适配程序坞**（可选）：最大化的窗口会停在 MyDock 的边缘，就像 Apple 程序坞一样。如果程序坞自动隐藏，窗口会占满整个屏幕。当 App 处于全屏时，MyDock 会隐藏，将指针移到边缘即可显示。
- **登录时打开**。
- **浅色或深色模式**：跟随你的 Mac。
- **17 种语言**：英语、西班牙语、加泰罗尼亚语、加利西亚语、巴斯克语、法语、德语、意大利语、葡萄牙语、挪威语、丹麦语、芬兰语、日语、简体中文、韩语、印地语和阿拉伯语。默认使用 Mac 的语言，也可在设置中选择。

## 使用方法

- **右键点按程序坞背景**：添加分隔线、空格、群组和小组件，以及主要选项（位置、大小、隐藏、使用的程序坞…）。
- **右键点按小组件**：打开其设置、切换紧凑版或宽版，或将其移除。
- **设置…**（在背景的右键菜单中）：包含所有选项的窗口。左侧是 **通用** 以及每个小组件的设置；**+** 按钮用于添加小组件。

> Apple 程序坞不允许把它的图标拖到其他 App 中：把图标拖出去会将其移除。请从访达把 App 添加到 MyDock。

## 权限

MyDock 只在需要时才请求权限，macOS 会记住你的选择：

| 用途 | 权限 |
|---|---|
| 当前位置的天气 | 定位（可选：不授权时可手动添加城市） |
| 废纸篓 | 访达（用于了解废纸篓是否有内容并清倒） |
| 即将发生的日程 | 日历 |
| 提醒事项 | 提醒事项 |
| 下载 | “下载”文件夹 |
| 截屏 | “桌面”文件夹（或你存储截屏的位置） |
| 窗口适配程序坞，以及右键菜单中已打开 App 的窗口和操作 | 辅助功能 |

如果你拒绝，小组件会显示“无权限”；点按即可前往相应设置进行授权。

## 隐私

- 没有账户，也没有分析统计。你的设置只保存在你的 Mac 上。
- 天气小组件只会向 [Open-Meteo](https://open-meteo.com) 发送四舍五入后的坐标（精度约 1 公里）以获取气温。城市名称通过 Apple 地图服务查询。
- 剪贴板历史只保存在内存中：不会写入磁盘，MyDock 退出时会清除，并且不会包含密码管理器拷贝的内容。

## 安全性

- **macOS 强化运行时**：其他程序无法向 MyDock 注入代码来利用它的权限。此外，MyDock 只能请求上表中的权限。
- **签名**：所有版本都使用同一个证书签名，因此 macOS 会把更新识别为同一个 App，并保留你的权限。
- **确认 `.dmg` 是否为正版**：在每个版本的页面上，GitHub 会在 *Assets* 中 `.dmg` 名称旁显示其 SHA-256 指纹。在“终端” App 中输入：

  ```bash
  shasum -a 256 ~/Downloads/MyDock-x.y.z.dmg
  ```

  结果必须与该指纹完全一致。如果不一致，请不要打开它。
- 请只从[官方版本页面](https://github.com/JotaRguezD/MyDock/releases)下载 MyDock。

## 常见问题

**可以不显示 Apple 程序坞吗？**
可以：右键点按 › **使用的程序坞 › 仅 MyDock**。MyDock 退出后，Apple 程序坞会恢复原样，即使 MyDock 崩溃或被强制退出也是如此。

**最大化窗口时，窗口会钻到 MyDock 下面。**
在“设置 › 通用”中打开 **窗口适配程序坞**，并授予“辅助功能”权限。

**为什么没有显示我正在听的歌？**
音乐小组件显示的内容与 macOS 在“控制中心”的“正在播放”中显示的相同。如果某个播放器没有出现在那里，MyDock 也无法看到它。

## 卸载

1. 关闭 **登录时打开**，然后选择 **退出 MyDock**。如果你使用的是“仅 MyDock”，Apple 程序坞会恢复原样。
2. 从“应用程序”中删除 MyDock。
3. 如果还想删除设置，请删除文件夹 `~/Library/Application Support/MyDock`。
